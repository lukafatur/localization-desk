Load your Canva folders, then pick where the designs should go.

Moving a design into a team-shared folder gives everyone with access to that folder access to the design. Canva only lets you move designs you own or can edit; view-only designs are skipped.

Always Pro quality

Auto: designs with “video” in the name download as MP4 video, everything else as a static file.

File names

Tokens: {design} design name · {page} page name · {n} page number · {nn} 01, 02… · {note} first line of the page's notes in Canva · {sep} separator. Empty parts and their separators are dropped.

Download everything in one go
  1. Press Copy download command.
  2. Open Terminal (Cmd+Space, type Terminal), paste, press Enter.
  3. All files land in , named as set in File names above, in one folder per locale if that's ticked.

Each link opens or downloads one file. Multi-page designs give one image per page. Links stop working after a few hours, so export again if one expires.
